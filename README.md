# 💕 Romantic Maze Game

A cute, romantic interactive maze game with pixel-art aesthetic.

## 🎮 Features

- **5 screens**: Welcome → Game Details → Maze Game → Success Dialogue → Night Sky Reward
- **Responsive**: Works on desktop (keyboard) and mobile (touch D-pad)
- **Pixel-art aesthetic**: Press Start 2P font, pastel pink/purple palette
- **Maze engine**: Recursive backtracking algorithm, guaranteed solvable
- **Animations**: Typing effect, floating moon, twinkling stars, shooting stars
- **Audio**: Built-in music player with mute toggle

**[Play the game!](https://agunghidayatz.github.io/romantic-maze-game/)**

## 🎵 Audio Asset

This game requires an audio file: `losing-us-raissanggiani.mp3`

**How to add:**
1. Place `losing-us-raissanggiani.mp3` in the root directory (same folder as `index.html`)
2. The game will automatically loop the audio on the final reward screen
3. A mute/unmute toggle is provided in the top-right corner

**Note:** The audio will not play until the player reaches Screen 5 (Final Reward).

## 🎯 How to Play

1. Click "Yes! I want to play, baby" on the welcome screen
2. Read the game details and click "Start Game"
3. Use **arrow keys** or **WASD** to navigate through the maze
4. On mobile, use the **on-screen D-pad** controls
5. Reach the rose 🌹 at the bottom-right corner to win!
6. Enjoy the romantic dialogue and night sky reward scene

## 🛠 Tech Stack

- Pure HTML, CSS, and vanilla JavaScript
- No frameworks, no build tools, no dependencies
- Single-file architecture (`index.html`)
- Inline SVG illustrations
- CSS animations and transitions

## 📱 Responsive Design

- **Desktop**: Keyboard controls (Arrow keys / WASD)
- **Mobile**: Touch D-pad controls (auto-detected)
- **Tablet**: Both control methods available

## 🎨 Customization

The game is easily customizable:
- Change colors in the CSS variables
- Replace SVG illustrations with your own
- Swap the audio file for any MP3
- Modify dialogue text in the JavaScript
